I developed **Drift** during my **Ouedkniss** internship—an intelligent error-tracking platform (based on a fork of GlitchTip).

* **The Stack:** Python (Django), TypeScript (Angular), Docker, PostgreSQL, GitLab CI/CD, and **Ollama (Local LLMs)**.
